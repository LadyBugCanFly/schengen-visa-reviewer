# Schengen Visa Reviewer

[中文](README.md) | [English](README.en.md)

一个面向普通申请人的**短期申根旅游签证材料自检 Skill**。

它不会预测或保证出签，而是在递交前帮你发现：材料缺失、日期冲突、行程不真实、资金解释不清和回国证据不足等问题。

## 能检查什么

- 按申请国家、递交地点和申请人情况，查找对应的官方材料清单并逐项核对；
- 核对申请表、机票、酒店、保险、请假和行程日期；
- 验证景点、地点、交通路线和预约要求，识别 AI 虚构或不现实的行程；
- 对照工资单、银行流水、在职证明、旅行预算和异常入账；
- 检查工作、学业、合法居留等按时回国的支持材料；
- 检查所有文件之间的人数、付款人、收入、日期和旅行目的是否一致；
- 用公开的欧盟常见拒签理由做递交前排查。

报告使用 A–D **材料准备度**等级，并把问题分成“必须修改、建议加强、可以优化”。这不是获签概率。

## 适用范围

当前版本只支持**短期申根旅游签证**，包括多国申根旅游。

商务、探亲访友、留学、工作、医疗、过境和长期签证不会套用旅游标准，也不会生成误导性的准备度评级。

法国申请会查找对应的法国官方要求，荷兰申请会查找荷兰要求；不会把一个国家的材料清单直接套到另一个国家。如果无法确认完全匹配的官方清单，报告会标为“临时审核”。

## 安装和使用

在支持从 GitHub 安装 Skill 的 Codex 中，提供本仓库地址并要求安装其中的 `schengen-visa-reviewer` Skill。安装后可以这样说：

> 使用 $schengen-visa-reviewer 检查我的法国短期旅游签证材料。我在新加坡递交。

开始前，Skill 会先确认旅行目的、负责国家、递交地点以及当前有哪些材料。

## 隐私提醒

上传前请遮盖护照号、身份证号、完整住址、银行账号、申请编号、条形码、签名和无关交易。

公开仓库不包含任何申请人的护照、银行流水、预订、拒签文件、照片或私人回测报告。

## 重要说明

本项目只做材料准备度检查，不代表使领馆决定，也不提供法律意见。官方要求可能变化，递交前应再次核对相应政府、使领馆或指定签证中心的最新要求。
